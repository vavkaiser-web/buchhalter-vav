# Бухгалтер VAV — локальная реализация кассы и чеков по утверждённому макету

Просмотр: двойной щелчок **«Открыть Бухгалтер.command»** (или `./start-demo.sh`) → http://127.0.0.1:3126/arbeit
Входы демо: `buch`, `andrej`, `oleg`, `ma_a`, `ma_b` · ПИН `demo-2409` (только локальная демо-база с вымышленными данными).
`./start-demo.sh --neu` — вернуть демо-данные в исходное состояние.

| Где | Что |
|---|---|
| `docs/REPORT.md` | отчёт для Андрея: что работает, проверки, отличия, ограничения |
| `docs/BACKUP-MIGRATION-PLAN.md` | резервная копия и выкладка (не выполнялись) |
| `docs/test-log-final.txt` | финальный прогон тестов с кодами выхода |
| `visual/out/` | сравнение с эталоном: `*-vergleich.png` (эталон / реализация / различия), `report.json` |
| `app/kasse/` | сервер: операции, права, деньги, рабочие дни, печать квитанций |
| `app/public/arbeit.html`, `arbeit.js` | экран по макету (CSS эталона дословно, сборка `tools/build-arbeit.py`) |
| `app/migrations/001_kasse.*.sql` | новые таблицы и откат |
| `tests/` | сценарии API, браузерные сценарии, миграция, CSS |
| `server-snapshot-2026-09-24/` (в основной папке) | копия серверного кода без секретов и данных, с хэшами |

Тесты: `./tests/migration.test.sh && node --test --test-concurrency=1 tests/*.test.js` (локальный Postgres на 55481, Chrome).
Сравнение с эталоном: `node tools/visual.js` при запущенном демо.
Боевой сервер этим кодом не менялся.
