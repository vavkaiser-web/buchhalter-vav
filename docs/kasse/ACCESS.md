# Касса VAV — управление доступом

## ВАЖНО: Правила (жёсткие ограничения)
- Реальных людей подключать ТОЛЬКО после решения Андрея
- Приглашения НЕ отправлять автоматически
- Демо-логины НЕ должны работать в продакшне
- PIN Андрея НЕ использовать для интеграции
- Служебные ключи НЕ помещать в браузер/источники/отчёты

## Роли

| Роль          | Описание              | Доступ к Кассе | Права в системе                          |
|--------------|----------------------|---------------|------------------------------------------|
| `gf`         | Geschäftsführer      | ✅ полный     | Все действия, утверждение, просмотр всего |
| `buchhaltung`| Бухгалтерия          | ✅ полный     | Проверка, утверждение, управление кассой  |
| `disponent`  | Диспонент            | ✅ очередь    | Просмотр очереди, согласование планов     |
| `mitarbeiter`| Сотрудник            | ✅ запросы    | Создание заявок, загрузка чеков, статусы  |
| `buero`      | Бюро                 | ❌ 403        | Нет доступа к Кассе VAV                  |

## Управление пользователями
- Файл: `{KASSE_DATA}/benutzer.json`
- Пароль: scrypt (N=16384, r=8, p=1), хранится хеш+соль
- Сессия: cookie `kassesess`, 30 дней, HttpOnly, SameSite=Lax

## Добавление нового пользователя
```bash
# На сервере с доступом к benutzer.json
node -e "
const crypto = require('crypto');
const salz = crypto.randomBytes(16).toString('hex');
const hash = crypto.scryptSync('НОВЫЙ_PIN', Buffer.from(salz,'hex'), 32).toString('hex');
console.log(JSON.stringify({login:'ИМЯ',name:'Отображаемое имя',rolle:'mitarbeiter',salz,hash}));
"
# Добавить в benutzer.json вручную
```

## Отзыв доступа
1. Удалить или отключить пользователя в `benutzer.json`
2. Сменить `KASSE_SECRET` (если нужен мгновенный отзыв всех сессий)
3. Перезапустить процесс

## Интеграционный токен (vavapp ↔ kasse-vav)
- Переменная: `KASSE_INTEGRATION_TOKEN`
- Тип: Bearer token (32+ байта случайных данных)
- Установить: в `/opt/kasse-vav/.env` (только на сервере, никогда в коде)
- Генерация: `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"`
- **ЗАПРЕЩЕНО**: передавать в браузер, логи, отчёты, коммиты
