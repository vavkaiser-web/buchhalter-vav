## 2. Миграция базы
- `app/migrations/001_kasse.up.sql` — только новые таблицы `buch_*` в mailops_prod + триггеры запрета удаления. Существующие таблицы не меняются. Выполняется в одной транзакции; если таблица с таким именем уже есть — падает целиком, ничего не меняя.
- Проверено локально: вверх → вставки (включая снятие) → запреты → вниз → вверх (`tests/migration.test.sh`).
- Откат: `001_kasse.down.sql` удаляет только таблицы 001. Если в них уже есть рабочие записи — сначала выгрузка этих таблиц (`pg_dump -t 'mailops_prod.buch_*'` по списку 001).

- Старый интерфейс `/` открывается как раньше; `/arbeit` — для бухгалтерии.
